# 功能选项说明

先选择「所有投影仪」或单台设备，再展开模块。「跟随默认」在单台设备下继承全局配置；「启用」「停用」是该范围的明确覆盖。未知选项保留兼容。

设备：决定是否发布该投影仪。HDMI 输入：可增加独立输入开关。画面模式、宽高比：按型号支持提供选择开关。附加控制：亮度、对比度、画面静音、HDR、测试图等，默认按需启用。

自动化传感器：预热中、投影就绪、冷却中独立显示；故障、灯泡时数依赖设备支持。Apple TV 遥控器：主开关控制整组，停用后收起下属按键。日志：控制诊断输出。Matter：需要 Homebridge 与子桥已启用 Matter，单独配对验收。

点击任意功能名称可查看用途。先在设置测试连接，可根据已发现的能力过滤当前设备不支持的功能。
