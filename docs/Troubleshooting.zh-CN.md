# 故障排查

先在「设置」检查当前 IP、协议、端口，点击「测试连接」，测试仅进行连接与状态读取，不开关机。ADCP 默认 53595，SDCP/PJ Talk 默认 53484。自动协议发现时建议不填写自定义端口。

如提示认证失败，核对投影仪网络设置中的 Requires Authentication 与管理员密码。默认用户名 root、默认密码 Projector，均可修改。无需认证时可清空密码。

保存失败会定位缺失或重复地址的投影仪。可以补全，也可点击移除并在页面内确认，然后保存。

待机时亮度和对比度显示关闭及历史数值；未获得历史数值时显示 0。真正离线或状态未知才显示未响应。电视持续未响应时检查 Homebridge 子桥是否运行、网络广播与固定端口，不要直接删除已有配对。
